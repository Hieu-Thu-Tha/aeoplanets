2) Payments, mock now, real later
Goal

Ship billing flows day one without committing to a gateway. Swap-in Stripe, Adyen, or Paddle later with no UI churn.

Approach

Domain, BillingPort interface in BE, BillingClient in FE

Contract

createCustomer(orgId)

createSubscription(orgId, planId, trialDays?)

updatePaymentMethod(orgId, paymentToken)

issueInvoice(orgId, amount, currency, meta)

cancelSubscription(orgId, atPeriodEnd)

webhook(event)

Mock provider

In-memory then Postgres tables, deterministic “test cards”

Webhook simulator UI to fire invoice.paid, invoice.payment_failed, subscription.updated

Frontend uses Payment Element shim that returns a paymentToken from a fake iframe, later replaced by Stripe Elements

Swap

Drop in StripeAdapter implementing BillingPort

Map mock events to Stripe event types in one place

Metering

Usage records from events bus aggregated nightly, per seat and per prompt job
