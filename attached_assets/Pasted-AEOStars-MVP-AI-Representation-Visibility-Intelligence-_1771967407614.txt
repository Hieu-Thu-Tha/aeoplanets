AEOStars MVP

AI Representation & Visibility Intelligence Platform

⸻

1. Onboarding & Initial Assessment

What It Does

Captures:
	•	Domain
	•	2–3 core competitors
	•	Category keywords
	•	Optional: target audience description
	•	Brand positioning statement

Then runs a baseline AI perception scan.

⸻

UI

Screen: “Let’s See What AI Thinks About You”

Minimal.

Fields:
	•	Domain input
	•	Competitor domains
	•	“What category are you in?”
	•	“What problem do you solve?”

CTA:
Run AI Assessment

⸻

Data Processing

Baseline AI scan should run asynchronous.

Reason:
	•	You will be querying multiple LLMs
	•	Running prompt batches
	•	Extracting structured insights

User sees:
Progress indicator:
“Scanning AI models… Analysing narrative… Comparing competitors…”

Initial report ready within 5–10 minutes.

⸻

Report Output

AI Snapshot Report
	•	200-word AI-generated brand summary
	•	Top 5 themes AI associates with brand
	•	Missing themes competitors have
	•	Sentiment indicator
	•	Presence score

This is the hook.

⸻

2. AI Visibility Monitoring Engine

This is the core.

⸻

What It Does

Tracks brand appearance across:

Prompt Types:
	•	Brand direct queries
	•	Category comparison queries
	•	Commercial intent queries
	•	Problem-based queries

Example:
“Best marketing automation platforms for UK SMEs”
“Alternatives to X”
“Who is the leader in Y”

Stores:
	•	Brand mentioned or not
	•	Position in response
	•	Sentiment
	•	Competitors included
	•	Citation present or not

⸻

UI

Dashboard: AI Visibility Overview

Top section:
	•	AI Share of Voice %
	•	Commercial Recommendation Score
	•	Category Authority Score
	•	Trend graph (last 30 days)

Middle section:
	•	Prompt categories filter
	•	Model filter
	•	Time filter

Lower section:
Table view:
Prompt | Appeared? | Position | Competitors | Sentiment | Citation

Clean. Analytical. No noise.

⸻

Data Processing

Two layers:
	1.	Daily asynchronous scheduled runs
	2.	Manual “Run Prompt Test” button

Scheduled runs ensure monitoring continuity.
Manual allows user experimentation.

4. Semantic Coverage Gap Analysis

Practical. Not over-engineered.

⸻

What It Does

Compares:

Your site vs competitors on:
	•	Topic clusters
	•	Entity mentions
	•	Structured data usage
	•	FAQ presence
	•	Comparison page presence

Outputs:

Missing topic clusters
Missing commercial intent pages
Missing FAQ structures

⸻

UI

Coverage Gap Screen

Visual:

Topic Map View:
Clusters shown as circles.
Green = strong coverage.
Red = weak.
Grey = competitor-owned.

Table view below:
Topic | You | Competitor A | Competitor B | Gap severity

Action column:
“Recommended Action”

⸻

Data Processing

Runs asynchronously weekly.

Manual refresh available.

What MVP Should NOT Do

Do not:
	•	Try to crawl entire web
	•	Over-engineer NLP visualisations
	•	Build custom model infrastructure
	•	Add MCP integrations
	•	Add APIs

That’s v2.

MVP proves:
	•	AI representation is measurable
	•	AI inclusion can be influenced
	•	Strategic clarity increases presence
